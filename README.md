# ⚡ EV Vehicle Market Dashboard - Power BI

## 📌 Project Overview

The **EV Vehicle Market Dashboard** is an interactive Power BI project developed to analyze the 2026 Electric Vehicle (EV) market dataset. This dashboard provides valuable insights into vehicle performance, pricing, battery specifications, driving range, and brand comparisons through dynamic and interactive visualizations.

The objective of this project is to transform raw EV market data into meaningful business insights that help users understand market trends and compare different electric vehicles.

---

## 🎯 Objectives

* Analyze the electric vehicle market using Power BI.
* Compare EV brands based on pricing and performance.
* Visualize battery capacity and driving range.
* Create an interactive dashboard using slicers and filters.
* Generate insights to support data-driven decision-making.

---

## 📊 Dashboard Features

* 📌 KPI Cards

  * Total Vehicles
  * Average Price
  * Average Battery Capacity
  * Average Driving Range

* 📈 Interactive Charts

  * Top 5 EV Brands
  * Brand-wise Vehicle Distribution
  * Price Analysis by Brand
  * Battery Capacity Comparison
  * Driving Range Analysis
  * Performance Analysis (Horsepower, Torque, Top Speed)

* 🎛 Interactive Filters

  * Brand
  * Year
  * Drive Type
  * Seating Capacity
  * Vehicle Variant
